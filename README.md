# Тернов Капитал

Сайт-визитка Ивана Тернова. Статический сайт (HTML, CSS, JS), без сборки и без CMS. Публикуется через GitHub Pages автоматически при каждом изменении в ветке `main`.

## Структура

```
index.html            разметка всех блоков
styles.css            стили
main.js               меню, анимации, кейсы, документы
data/cases.json       тексты кейсов
data/documents.json   список документов (создаётся автоматически, руками не править)
files/                файлы для раздела «Полезные документы»
assets/               логотип, фавиконка, фото
scripts/              скрипт, который собирает список документов
```

## Как добавить документ

1. Откройте папку `files/` на GitHub.
2. Нажмите **Add file → Upload files**, перетащите файл, нажмите **Commit changes**.
3. Через 1–2 минуты документ появится на сайте.

Название на сайте берётся из имени файла: `Договор_оказания_услуг.docx` превратится в «Договор оказания услуг». Чтобы задать порядок, начните имя с номера: `01_Договор.docx`, `02_Акт.docx` (номер на сайте не показывается).

Поддерживаются: pdf, doc, docx, xls, xlsx, odt, rtf, txt, zip. Чтобы убрать документ, удалите файл из `files/`.

Файл `files/Пример_шаблона.txt` лежит для демонстрации, его можно удалить.

## Как добавить или изменить кейс

Откройте `data/cases.json` на GitHub, нажмите на карандаш и отредактируйте. Каждый кейс выглядит так:

```json
{
  "title": "Название кейса",
  "summary": "Короткое описание для карточки",
  "tags": ["Роспотребнадзор"],
  "image": "assets/cases/case-1.jpg",
  "blocks": [
    { "title": "Задача", "text": "..." },
    { "title": "Что сделали", "text": "..." },
    { "title": "Результат", "text": "..." }
  ]
}
```

Если `image` пустой, показывается заглушка. Фото загружайте в `assets/`.

## Как заменить фото-заглушки

Заглушки в `index.html` — это блоки с классом `ph`. Замените блок на картинку, например в первом экране:

```html
<div class="hero__photo"><img src="assets/ivan.jpg" alt="Иван Тернов" style="width:100%;height:100%;object-fit:cover;border-radius:16px"></div>
```

## Подключение домена .ru

1. В репозитории: **Settings → Pages → Custom domain**, впишите домен (например `ternov-capital.ru`), нажмите **Save**. GitHub сам создаст файл `CNAME`.
2. У регистратора домена (REG.RU, RU-CENTER и т.п.) в DNS-записях добавьте:

   | Тип   | Имя | Значение                         |
   |-------|-----|----------------------------------|
   | A     | @   | 185.199.108.153                  |
   | A     | @   | 185.199.109.153                  |
   | A     | @   | 185.199.110.153                  |
   | A     | @   | 185.199.111.153                  |
   | CNAME | www | `<логин-владельца>.github.io.`   |

3. Подождите от 15 минут до суток, пока обновится DNS. Затем в **Settings → Pages** включите **Enforce HTTPS**.

## Передача заказчику

**Settings → General → Danger Zone → Transfer ownership**, укажите логин GitHub заказчика. Сайт и история изменений переедут целиком. После передачи адрес вида `*.github.io` сменится, а свой домен продолжит работать (проверьте поле Custom domain в Settings → Pages и CNAME-запись для `www`).
